# SmartLists Go – Feedback

**English** · [Deutsch](#deutsch)

This is the place for **bug reports, questions and ideas** for the app **SmartLists Go** – lists and notes for Android,
on the device alone or together with [Home Assistant](https://www.home-assistant.io/).

The app's source code is not public. This repository contains no code – it only exists so you can reach me.

| | |
|---|---|
| Website | <https://ha-smartlists.com> |
| SmartLists (Home Assistant integration) | <https://github.com/m3m0rex/ha_smartlists> |
| SmartDiscounts (dashboard card) | <https://github.com/m3m0rex/ha_smartdiscounts-card> |

## Report a bug

1. In the app open **Settings → Security → Privacy → Create an error report**.
2. The app shows you the report (app version, operating system, the latest errors – **no lists, no notes, no
   addresses**) and copies it to the clipboard.
3. [Open a new issue](../../issues/new/choose), choose **Bug report**, paste the report and describe what you did and
   what you expected.

Please check the [open issues](../../issues) first – maybe it is already known.

## Suggest something

[Open a new issue](../../issues/new/choose) and choose **Idea**. One idea per issue, and tell me what you would use
it for – that helps more than a description of the solution.

## Where each kind of report belongs

| It is about … | Report it here |
|---|---|
| the app SmartLists Go | this repository |
| lists, the SmartLists card or the sidebar page in Home Assistant | [ha_smartlists](https://github.com/m3m0rex/ha_smartlists/issues) |
| the offers card | [ha_smartdiscounts-card](https://github.com/m3m0rex/ha_smartdiscounts-card/issues) |

Not sure? Just write here – I will move it.

## Before you post

- **Issues are public.** Do not post passwords, access tokens, the address of your Home Assistant, e-mail addresses
  or the contents of private lists and notes. Screenshots: blur anything personal.
- **Security problems** do not belong in a public issue. Please write to the e-mail address in the
  [legal notice](https://ha-smartlists.com/en/legal-notice/).
- Write in **English or German**.
- This is a private, free project run in my spare time. I read everything, but an answer can take a few days and
  there is no guarantee that a wish will be built.

## Privacy and legal notice

- The app sends nothing on its own. A report only reaches me when you post it here yourself.

## Deutsch

Hier meldest du **Fehler, Fragen und Ideen** zur App **SmartLists Go** – Listen und Notizen für Android, nur auf dem
Gerät oder zusammen mit Home Assistant.

Der Quelltext der App ist nicht öffentlich. Dieses Repository enthält keinen Code; es gibt es nur, damit du mich
erreichen kannst.

### Fehler melden

1. In der App **Einstellungen → Sicherheit → Datenschutz → Fehlerbericht erstellen** öffnen.
2. Die App zeigt dir den Bericht (Fassung der App, Betriebssystem, die letzten Fehler – **keine Listen, keine Notizen,
   keine Adressen**) und kopiert ihn in die Zwischenablage.
3. [Neues Issue anlegen](../../issues/new/choose), **Bug report** wählen, den Bericht einfügen und beschreiben, was du
   getan und was du erwartet hast.

Schau vorher in die [offenen Issues](../../issues) – vielleicht ist es schon bekannt.

### Etwas vorschlagen

[Neues Issue anlegen](../../issues/new/choose) und **Idea** wählen. Eine Idee je Issue, und schreib dazu, wofür du sie
brauchst.
